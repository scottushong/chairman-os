# 프로세스 차트 — 구글 시트 연결 (서비스 계정, 읽기 전용)

0071 «프로세스 차트» 메뉴(`/process-charts`)가 팀 시트의 업무를 **업무 관리 · 캘린더**로 가져오려면, 앱이 시트를 읽을
**구글 서비스 계정** 하나가 필요합니다. 대표가 아래를 한 번만 따라 하면 됩니다(약 15분).

- 앱은 시트를 **읽기만** 합니다(권한 범위 `spreadsheets.readonly`). 시트를 고치거나 지우지 않습니다.
- «웹에 게시» 주소는 화면에 시트 그림을 띄우는 데만 씁니다. 업무를 가져오는 것은 이 서비스 계정입니다.
- **돈 드는 설정이 없습니다.** Google Sheets API는 요금이 없고(분당 읽기 횟수 한도만 있음), 이 절차는 결제 계정을
  연결하지 않습니다. 중간에 «결제 계정 연결», «무료 체험 시작», «업그레이드»가 나오면 **누르지 말고 닫습니다.**
- 키 파일(JSON)은 비밀번호와 같습니다. 메일 · 메신저 · 저장소에 올리지 말고, 아래 6단계에서 Vercel에 붙여 넣은 뒤 지웁니다.

---

## 1. 구글 클라우드 프로젝트 만들기

주소:

```
https://console.cloud.google.com/projectcreate
```

1. 회사 구글 계정으로 로그인합니다.
2. **프로젝트 이름**: `chairman-os-sheets` (아무 이름이나 괜찮습니다)
3. **만들기** 클릭
4. 화면 위쪽 프로젝트 선택 상자에 `chairman-os-sheets`가 보이는지 확인합니다.

## 2. Google Sheets API 켜기

주소:

```
https://console.cloud.google.com/apis/library/sheets.googleapis.com
```

1. 위쪽 프로젝트가 `chairman-os-sheets`인지 확인합니다.
2. **사용**(Enable) 클릭
3. «결제 사용 설정»이 나오면 닫습니다 — Sheets API는 결제 없이 켜집니다.

## 3. 서비스 계정 만들기

주소:

```
https://console.cloud.google.com/iam-admin/serviceaccounts
```

1. **+ 서비스 계정 만들기** 클릭
2. **서비스 계정 이름**: `process-chart-reader`
3. **만들고 계속하기** 클릭
4. «이 서비스 계정에 프로젝트 액세스 권한 부여»(역할) — **아무것도 고르지 않고** **계속** 클릭
5. **완료** 클릭
6. 목록에 생긴 이메일을 복사해 둡니다. 모양: `process-chart-reader@chairman-os-sheets.iam.gserviceaccount.com`

## 4. 키(JSON) 만들기

같은 주소(3단계 목록)에서:

```
https://console.cloud.google.com/iam-admin/serviceaccounts
```

1. 방금 만든 `process-chart-reader` 이메일을 클릭
2. 위 탭에서 **키** 클릭
3. **키 추가** → **새 키 만들기**
4. **JSON** 선택 → **만들기**
5. 컴퓨터에 `chairman-os-sheets-xxxx.json` 파일이 내려받아집니다.

> «서비스 계정 키 생성이 사용 중지됨»(조직 정책 `iam.disableServiceAccountKeyCreation`)이 나오면 여기서 멈추고 알려 주세요.
> 회사 Google Workspace 조직의 기본 보안 정책입니다. 정책을 끄는 일은 따로 판단합니다(직접 끄지 마세요).

## 5. 시트마다 서비스 계정에 «뷰어»로 공유

팀 시트(연구소 · 영업 · 경영지원)마다 한 번씩(시트 목록 주소 — 비용 없음):

```
https://docs.google.com/spreadsheets/
```

1. 구글 시트를 엽니다.
2. 오른쪽 위 **공유** 클릭
3. 3단계에서 복사한 서비스 계정 이메일을 붙여 넣습니다.
4. 오른쪽 권한을 **뷰어**로 둡니다(편집자 아님).
5. **이메일 알림 보내기** 체크를 끕니다(서비스 계정은 메일을 받지 않습니다).
6. **공유** 클릭

시트의 첫 줄(또는 맨 위 5줄 안)에 아래 제목 줄이 있어야 합니다. 순서는 달라도 됩니다.

| ID | 단계 | 업무명 | 담당자 이메일 | 시작일 | 마감일 | 상태 | 비고 |
|----|------|--------|---------------|--------|--------|------|------|

- **ID**: 줄마다 다른 값(예: `S-01`). 앱은 (회사, 팀, ID)로 같은 업무를 알아봅니다 — 한 번 정한 ID는 바꾸지 않습니다.
- **담당자 이메일**: 직원이 앱에 로그인하는 이메일. 못 찾으면 «담당 미정»으로 들어오고 경고가 남습니다.
- **시작일 · 마감일**: `2026-10-12` 모양(점 · 빗금도 됨). 틀리면 그 줄은 건너뛰고 경고가 남습니다.
- **상태**: 예정 · 진행 · 완료 · 보류 중 하나. 다른 값은 «예정»으로 들어오고 경고가 남습니다.
- 줄을 지우면 앱의 업무는 지워지지 않고 «시트에서 사라짐»으로 남습니다.

## 6. Vercel에 키 넣기

주소:

```
https://vercel.com/dashboard
```

1. **chairman-os** 프로젝트 클릭
2. **Settings** → 왼쪽 **Environment Variables**
3. **Key**: `GOOGLE_SHEETS_SA_JSON`
4. **Value**: 4단계 JSON 파일을 메모장으로 열어 **내용 전체**를 복사해 붙여 넣습니다(`{`부터 `}`까지).
5. **Environments**: Production (staging 시험도 하려면 Preview도)
6. **Save** 클릭
7. **Deployments** → 맨 위 배포의 **⋯** → **Redeploy** (환경변수는 다시 배포해야 붙습니다)
8. 내려받은 JSON 파일을 지웁니다(휴지통 비우기까지).

이미 있어야 하는 값(야간 Job과 같음 — 새로 만들 필요 없음): `AI_AGENT_EMAIL` · `AI_AGENT_PASSWORD`(동기화를 넣는 계정) · `CRON_SECRET`(새벽 자동 동기화).

## 7. 앱에서 탭마다 시트 연결

주소:

```
https://chairman-os-eosin.vercel.app/process-charts
```

1. 아래 **시트 연결 관리**에서 탭(연구소 · 영업 · 경영지원)마다 **시트 파일 ID 또는 편집 주소** 칸에
   그 시트의 주소창 주소(`https://docs.google.com/spreadsheets/d/…/edit…`)를 그대로 붙여 넣습니다. 앱은 ID만 저장합니다.
2. 읽을 탭이 첫 탭이 아니면 **탭 이름**을 넣습니다(비우면 첫 탭).
3. **시트 연결 저장** 클릭
4. 위에서 그 팀 탭을 누르고 **지금 동기화** 클릭 → «읽은 줄 · 새로 · 바뀜 · 사라짐 · 건너뜀 · 경고»가 나오면 끝입니다.

이후에는 새벽 3시(한국 시각)에 하루 한 번 자동으로, 그리고 누군가 화면을 열 때 마지막 동기화가 10분보다 오래됐으면 다시 읽습니다.
«지금 동기화»는 같은 팀에 1분에 한 번만 됩니다.

## 문제가 생기면

| 화면 문장 | 할 일 |
|-----------|-------|
| 연결 전 — 구글 시트 서비스 계정이 아직 연결되지 않았습니다 | 6단계(Vercel 값 · Redeploy) |
| 연결 전 — 이 탭에는 아직 시트 파일이 연결되지 않았습니다 | 7단계 |
| 서비스 계정이 이 시트를 볼 수 없습니다 | 5단계(그 시트에 공유) |
| 시트를 찾지 못했습니다 | 7단계 주소 · ID 다시 붙여 넣기 |
| 탭 이름을 찾지 못했습니다 | 7단계 탭 이름 비우거나 고치기 |
| 제목 줄을 찾지 못했습니다 | 5단계 제목 줄 |
| 동기화 계정에 로그인하지 못했습니다 | `AI_AGENT_EMAIL` · `AI_AGENT_PASSWORD` 확인 |
