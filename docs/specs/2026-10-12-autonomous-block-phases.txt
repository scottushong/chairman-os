- 선매입 효과는 매출원가에 이미 들어간다. 구매이익을 따로 더하거나 보여 주지 않는다
- 공식 재고평가방법은 세무사 확인 전이다. 확인 전까지 «관리용 잠정 기준(원료별 월 가중평균)»으로 표시하고, 설정 하나로 바꿀 수 있게 한다

요약판(원문이 없을 때):
1. 목적:
   많이 산 달에 손익이 나빠지는 왜곡을 없앤다. 매입을 몇 달로 나누는 기능이 아니다
   매입 · 투입 · 판매 · 지급을 나누고 월말 재고를 반영한다
2. 유지:
   Actual · Current · Market · Forecast 체계, 견적 · 마진 등급 · 가격 예외 · BOM 비공개 · 원가 권한은 바꾸지 않는다
   견적용 원가와 실적 손익용 재고평가 · 매출원가를 분리한다
   Current · Market이 바뀌어도 확정된 과거 달은 바뀌지 않는다
3. 우선:
   회사 전체 월별 손익. 제품별 근거가 없다고 회사 전체를 막지 않고, 회사 전체가 된다고 제품별을 된 것으로 치지 않는다
4. 흐름:
   원료 매입 → 원료 재고 → 생산 투입 → 재공품 → 완제품 → 판매분 매출원가
   ① 원료 사용액 = 기초 원료 + 순매입 − 기말 원료
   ② 제조비용 = ① + 제조 인건비 + 제조경비
   ③ 완성품 제조원가 = 기초 재공품 + ② − 기말 재공품
   ④ 매출원가 = 기초 완제품 + ③ − 기말 완제품
   ⑤ 매출총이익 = 매출 − ④
   ⑥ 영업이익 = ⑤ − 판관비
   반품 · 폐기 · 재고조정 · 평가손실 · 비생산 출고는 성격별로 나눈다
   중복 금지: 재고조정과 비용 이중 / 제조비 재차감 / 판관비를 재고에 배분
   배부 기준이 없으면 잠정 · 확인 필요
   귀속월은 인식 기준(입금 · 지급일로 대체 금지)
5. 원료별 월 가중평균:
   = (기초 금액 + 순매입 금액) ÷ (기초 수량 + 순매입 수량)
   투입원가 = 확인된 투입수량 × 그 단가
   원료끼리 섞지 않는다. 이동평균(Current)과 구분
   투입 기준 결과와 재고 증감 결과를 대사하고 차이는 표시만(자동으로 맞추지 않음)
   기초 = 전월 확정 기말. 첫 달은 명시 입력. 없으면 0이 아니라 미입력
   수량 0 · 음수 나눗셈 방지. 근거가 없으면 최신 구매가로 조용히 대체 금지. 정밀 수치, 반올림 시점 일관
6. BOM 없이 재공품 · 완제품:
   0072 평가금액을 쓴다. 포함 범위 일치 · 중복 금지 · 누락 ≠ 0
   제품별 실제 마진은 근거가 없으면 «계산 불가 / 추정»(기준 기록). kg 비율 단순 배분을 실제 원가로 표시 금지. 배부차이를 숨기지 않음
7. 기존과 연결:
   기존 손익이 A/B/C/D 중 무엇인지에 맞춰 필요한 곳만 고친다. 재고 증감 이중 가산 금지, 새 매출원가 적용 때 기존 매입비용 남기기 금지
   «기존 손익 + 기말 재고 − 기초 재고»는 검산용으로만(일괄 보정 기능 금지)
   0067의 «LOT 없으면 출고일 Current»가 당시 저장값인지 확인. 잠정이면 확정 매출원가와 구분. 최신 Current 소급 금지. 잠정과 마감 차이는 조정 내역으로
   Market · Forecast를 실적 원가로 대체 금지. 시장가 하락으로 재고금액 자동 변경 금지(평가손실은 승인 절차)
8. 손익과 현금:
   매입액 · 원료대금 지급액 · 투입원가 · 매출원가를 따로
   외상은 인식월 ≠ 지급월. 선급금은 원가 아님. 전월 매입의 이번 달 지급은 원가 아님
   현금은 자금흐름 실제 지급 기준. 차이는 부가세 · 선급금 · 외상 · 시점으로 설명
   «이익은 났지만 선매입 지급으로 현금은 줄었다»가 보여야 한다. 이익과 현금을 같게 맞추지 않는다
9. 화면(기존 화면 확장, 새 대형 대시보드 금지):
   [손익] 매출 · 매출원가 · 매출총이익 · 판관비 · 영업이익
   [재고 · 원가 근거] 원료 매입 · 투입원가 · 기초 · 기말 원료 / 재공품 / 완제품 · 재고조정 · 대사 차이
   [자금 참고] 원료대금 실제 지급 · 자금흐름 연결
   [자료 상태] 입력 중 / 잠정 / 내부 마감 확정 · 누락 · 평가방법 · 계산 버전 · 마감일
   마감 조건: 기초 = 전월 기말 · 중요 누락 · 미승인 조정 없음 · 허용오차 통과(기본 1,000원, 설정). 모자라면 잠정
   원본은 고치지 않고 보정값 · 사유를 따로. 과거 달 수정 → 이후 달 «재마감 대상»(자동 덮어쓰기 금지)
   같은 입력 = 같은 결과, 재업로드 · 재계산 중복 금지
   권한은 화면 · API · 내보내기 · 로그 모두
10. 시험(금액 단위 · 가정 명시):
   T1 9억 선매입 후 매달 3억 사용 · 매출 5억 · 판관비 1억 → 매달 매출원가 3억 · 영업이익 1억 · 원료 재고 6억/3억/0, 첫 달 현금지출 9억이 손익을 바꾸지 않음
