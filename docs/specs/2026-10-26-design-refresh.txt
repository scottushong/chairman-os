묻지 말고 끝까지. 마지막에 한 번만 보고. 멈추지 않는 규칙·배포 허용·Expand-only는 0094~0097 블록과 같다.

■ 원칙
- 기능·데이터·메뉴 이름·주소는 하나도 바꾸지 않는다. 바꾸는 것은 색·글꼴·간격·카드·버튼·표·배지·사이드바·헤더의 «모양»뿐.
- 방법은 디자인 토큰(색·글꼴·반경·그림자) 한 곳을 바꾸고, 토큰을 안 쓰고 색을 직접 박은 곳을 전부 토큰으로 옮기는 것.
  화면마다 따로 손대지 않는다. 손댄 뒤에도 토큰을 안 쓰는 곳이 남으면 check:design 이 잡는다.
- 스위치 ui_theme (설정 → 화면 모양: «새 모양(기본)» / «예전 모양»). 사람마다 고를 수 있고 기본은 새 모양.
  예전 토큰은 지우지 말고 theme=classic 으로 남긴다.

■ 시안에서 가져올 것
- 바탕: 따뜻한 크림(시안의 본문 배경) · 카드는 흰색에 아주 옅은 테두리와 부드러운 그림자 · 모서리 12~14px.
- 사이드바: 진녹색 바탕, 흰 글자, 선택 항목은 한 단계 밝은 녹색 칸. 위에 왕관 아이콘 + «CHAIRMAN OS» + 작은 «EXECUTIVE PLATFORM».
  메뉴 항목은 아이콘 + 글자, 펼침 화살표. 맨 아래 «설정». 메뉴 이름·순서·권한은 지금 그대로(시안의 메뉴 목록을 따르지 않는다).
- 헤더: 가운데 검색창(지금 검색 기능이 있으면 연결, 없으면 «준비 중» 비활성), 오른쪽 알림·설정·사람(이름·역할). 환율 띠는 데이터 없으니 넣지 않는다.
- 글꼴: 제목은 시안처럼 세리프 느낌(Noto Serif KR 또는 비슷한 무료 글꼴), 본문은 지금 산세리프. 숫자는 tabular.
- 포인트 색: 금색(제목 옆 왕관·강조), 녹색(저장·정상), 주황(주의·검토), 빨강(위험·기한 지남). 배지 모양은 시안의 둥근 알약.
- 표: 머리줄 옅은 바탕, 줄 구분선 아주 옅게, 숫자 오른쪽 정렬, 증감 ↑↓ 색.
- 버튼: 주 버튼 진녹색 채움, 보조 버튼 흰 바탕 테두리, 편집 모드 버튼은 금색 테두리(시안 «편집 모드»).
- 어두운 모드: 지금 있으면 같은 토큰으로 어두운 판도 만든다(크림 → 짙은 회녹, 카드 → 한 단계 밝게). 없으면 만들지 않는다.

■ 적용 범위
- 대표 화면·직원 화면·전자결재·재무·투자·내 홈·기억·설정·로그인 — 전부. 직원 화면에 «회장» 글자 금지 → «대표»(이번에 전수 검사).
- 폰 390px: 글자 13px 이상·누르는 칸 44px 이상(check:mobile 전체 126화면 통과). 사이드바는 폰에서 서랍.
- 기존 check:* 전부 그대로 통과(기능 안 바뀜을 증명).

■ 검사
- check:design: 토큰 밖의 색(#hex·rgb 직접 사용) 0건, 글꼴 직접 지정 0건, 두 테마 모두 대비(WCAG AA) 통과.
- 스크린샷 전·후 비교 — 주요 12화면 × PC·폰 × 새/예전 모양 → docs/onboarding/design-shots/.
- 마이그레이션: 사용자 설정에 ui_theme 칸 하나(Expand-only) — 0098.
