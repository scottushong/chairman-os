# 직원 초대 안내 (사용자 관리자용)

**대상** 대표가 «DY 사용자 관리자»를 켜 준 사람  ·  **화면** 왼쪽 메뉴 **사용자 · 권한** (…/settings/users)

---

## 1. 초대 칸 설명 — 화면 위 **«직원 초대 · DY (주)»** 버튼

| 칸 | 무엇을 적나 |
|---|---|
| **이메일** (필수) | 그 사람이 가입할 이메일. **이 주소로만** 가입됩니다. 오타가 없는지 두 번 보세요 |
| **이름** (필수) | 한글 이름. 영문 이름 · 직함은 비워도 됩니다 |
| **역할** | **사원** 또는 **팀장**. 임원 이상은 대표가 직접 초대합니다 |
| **팀** (필수) | 그 사람이 일할 팀. 내가 팀장인 팀은 목록에 없습니다 |
| **상사** (필수) | 그 사람의 결재 · 업무를 보는 사람. 비어 있으면 저장 버튼이 꺼집니다 |
| **보안등급** | 모르면 **일반** 그대로. 내 등급보다 높게는 줄 수 없습니다 |
| **권한** | 아래 3절 |

## 2. 팀 · 상사 고르는 법

- **팀**은 실제로 일할 팀. 목록에 없으면 대표에게 팀을 만들어 달라고 하세요.
- **상사**는 그 팀에 **팀장이 있으면 그 팀장**, 없으면(예: 경영지원) **대표**.
- 목록에 **나 자신은 없습니다** — 사용자 관리는 사람을 들이는 일이지, 그 사람의 일을 보는 일이 아닙니다.

## 3. 권한 체크 기준

체크 칸은 **내가 가진 권한만** 보입니다. 필요한 것만 켭니다.

| 권한 | 켜는 경우 |
|---|---|
| **결재 올리기** | 체크 칸이 아닙니다 — 새 직원은 기본으로 켜집니다(대표가 끌 수 있음) |
| **DY 재무 입력** | 전표 · 월별 손익 · 공식 결산을 입력할 사람만 (경영지원) |
| **DY 문서 등록** | 문서 링크 · 폴더를 등록할 사람만 |

- **월 마감**은 줄 수 없습니다(대표 · CFO만).
- 잘못 켰으면 가입 전에는 초대를 **취소**하고 다시 초대합니다. 가입한 뒤에는 대표에게 끄기를 요청합니다.

## 4. 가입 안내 보내기

1. **초대 저장**을 누릅니다. 대표에게 알림이 자동으로 갑니다.
2. 초록 상자의 **«가입 안내 문구 복사»**를 누릅니다.
3. 카톡 · 문자에 **붙여 넣어** 본인에게 보냅니다. 문구에 가입 주소(…/signup)와 순서가 들어 있습니다.
   (본인은 그 이메일로 가입 → **인증 메일** 링크 누르기 → 비밀번호 12자 이상)

## 5. 가입 후 확인

- 아래 **«대기 중인 초대»** 목록에서 그 사람이 빠지고 **«지난 초대»**에 **«수락됨»**으로 보이면 가입이 끝난 것입니다.
- 가입하는 순간 고른 권한이 바로 붙습니다. 본인에게 **내 홈**이 열리는지, **새 요청**(결재 올리기)이 되는지 물어보세요.
- 가입한 사람의 결재 · 업무는 **나에게 보이지 않습니다.** 정상입니다.
- 초대 **취소**는 내가 보낸 초대 중 **아직 가입하지 않은 것**만, 목록 오른쪽 **«초대 취소»**로 합니다.

## 6. 막힐 때

| 화면에 나온 말 | 할 일 |
|---|---|
| «사원 · 팀장만…» · «본인이 가진 권한만…» | 임원 이상 · 그 권한은 대표에게 부탁합니다 |
| «이 이메일로는 초대할 수 없습니다» | 내 예전 초대면 **취소** 후 다시. 아니면 이미 초대 · 가입된 사람 — 대표에게 확인 |
| «오늘 초대를 너무 많이 했습니다» | 24시간 20건까지(**취소한 초대도 셉니다**). 더 필요하면 대표에게 |
| «등록되지 않은 이메일» · 인증 메일이 안 옴 | 철자가 초대와 같은지(다르면 취소 후 다시) · 스팸함 · 가입을 시작한 그 기기에서 링크 열기 |
| «직원 초대» 버튼이 없음 | 사용자 관리자 권한이 꺼졌습니다(그때 보낸 대기 초대도 자동 취소). 대표에게 문의 |
| 본인이 가입했는데 아무것도 안 보임 · 다시 초대가 «초대할 수 없습니다» | 가입하는 사이 내 권한이 꺼진 경우입니다. 대표가 Supabase에서 그 계정을 지운 뒤 다시 초대합니다 |
